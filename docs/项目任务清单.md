## 1. 使用说明

**状态图例**

| 标记 | 含义 |
|---|---|
| `已完成` | 产出物已存在且验收标准已实测通过 |
| `进行中` | 已开始，验收未通过 |
| `待开始` | 未开始，无阻塞 |
| `阻塞` | 依赖外部条件（密钥、人工确认、环境） |
| `暂缓` | 明确不做，原因记录在备注 |

**勾选规则**：一个任务只有满足"产出物存在 + 验收标准可复现"才能置为 `已完成`。仅"代码写完了"不算。
